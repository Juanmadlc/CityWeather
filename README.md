I develop an app called CityWeather in my free time on weekends. It's a SwiftUI app for visualizing the weather, and I use it as a "seed" project to have a reusable architectural foundation for other projects that need to create new applications. 
It includes layer separation, design patterns, persistence, service consumption, and more.
